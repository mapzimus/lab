Box art & naming from the libretro-thumbnails project (No-Intro / Redump sets). Sizes are per-platform estimates for budgeting, not exact file sizes. Selections stay in this browser (localStorage) — export to move them.

Use the data. Everything here is plain JSON, no key required: data/platforms.json lists the platforms, and data/<id>.json (e.g. data/snes.json) holds each library — t title, f box-art file, s size in MB, d disc count, h tag (top-seller / classic / hidden-gem), y year, and g/dv/pb indexes into data/<id>.meta.json (genre / developer / publisher). Links are shareable too: the URL tracks the platform and filter you're viewing.

Known gaps, stated plainly. Release years, genres and studio credits come from libretro-database and are uneven upstream — years exist for most cartridge platforms but none of the disc ones, and a year is the title's original release, which for early ports can predate the North American date. Descriptions exist only for PlayStation and PS2. Xbox 360 and PS3 libraries come from Redump DATs with measured image sizes but almost no box art. Arcade and DOS sets carry no region tags, so those two tabs aren't NA-filtered.
